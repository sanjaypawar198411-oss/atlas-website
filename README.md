# Stonic AI Clone (stonicai.com)

100% exact, high-fidelity replica of **Stonic AI** ([stonicai.com](https://stonicai.com/)).

- **Complete Visual & Interactive Experience**:

  - Theme switcher demonstration (Crimson, Emerald, Cyan) with real-time responsive styling
  - Agent Town Showcase
  - Voice Assistant Core diagrams & circuits
  - World Monitor 3D globe display
  - Stonic Mobile Remote showcase
  - Pricing Plans & FAQ interactive accordion
  - Founder story & Social channels

## How to Run Locally

You can run the built-in Node.js server:

```bash
npm start
```
or:
```bash
node server.js
```

Then open your browser and navigate to:
**[http://localhost:1827](http://localhost:1827)**

---

## Deploying
This folder is ready to deploy on any static or Node host:
- **Vercel / Netlify / Cloudflare Pages / GitHub Pages**: Deploy directory directly.
- **Node.js VPS / Docker**: Run `node server.js`.
